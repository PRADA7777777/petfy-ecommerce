🐾 PETFY API - Pedidos

Base URL: https://api.petfy.com/v1

Endpoints Disponibles

GET /pedidos

Obtener todos los pedidos del usuario

// Headers
Authorization: Bearer eyJhbGciOiJIUzI1NiIs...

// Response
{
  "status": "success",
  "data": [
    {
      "id": "ped-001",
      "fecha": "2024-06-24",
      "estado": "entregado",
      "total": 19999,
      "items": [...]
    }
  ]
}

POST /pedidos

Crear nuevo pedido

// Request
{
  "items": [
    { "producto_id": "prod-01", "cantidad": 1 }
  ],
  "direccion_envio": "Calle 123 #45-67, Bogotá",
  "metodo_pago": "mercadopago"
}

// Response
{
  "status": "success",
  "data": {
    "id": "ped-002",
    "total": 19999,
    "envio": 3990,
    "total_final": 23989,
    "estado": "pendiente",
    "payment_url": "https://mercadopago.com/..."
  }
}

GET /pedidos/:id

Obtener detalle de pedido

POST /pedidos/:id/cancelar

Cancelar pedido

💳 Integración con Pasarelas de Pago

// MercadoPago
POST /api/pedidos/pagar/mercadopago
→ Redirige a checkout MP

// PayPal  
POST /api/pedidos/pagar/paypal
→ Redirige a PayPal

// Stripe
POST /api/pedidos/pagar/stripe
→ Procesa pago con Stripe
