🐾 PETFY API - Usuarios

Base URL: https://api.petfy.com/v1

Endpoints Disponibles

POST /usuarios/registro

Crear nueva cuenta

// Request
{
  "nombre": "Juan",
  "apellido": "Pérez",
  "email": "juan@email.com",
  "password": "********",
  "telefono": "+573001234567"
}

// Response
{
  "status": "success",
  "message": "Cuenta creada exitosamente",
  "data": {
    "id": "usr-001",
    "nombre": "Juan",
    "email": "juan@email.com",
    "token": "eyJhbGciOiJIUzI1NiIs..."
  }
}

POST /usuarios/login

Iniciar sesión

// Request
{
  "email": "juan@email.com",
  "password": "********"
}

// Response
{
  "status": "success",
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "data": {
    "id": "usr-001",
    "nombre": "Juan Pérez",
    "email": "juan@email.com"
  }
}

GET /usuarios/perfil

Obtener perfil (requiere token)

// Headers
Authorization: Bearer eyJhbGciOiJIUzI1NiIs...

// Response
{
  "status": "success",
  "data": {
    "id": "usr-001",
    "nombre": "Juan",
    "apellido": "Pérez",
    "email": "juan@email.com",
    "telefono": "+573001234567",
    "direcciones": [...],
    "created_at": "2024-06-24T00:00:00Z"
  }
}

PUT /usuarios/perfil

Actualizar perfil

POST /usuarios/recuperar

Recuperar contraseña
